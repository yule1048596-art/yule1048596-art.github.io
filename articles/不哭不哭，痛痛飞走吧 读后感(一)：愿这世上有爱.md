# 不哭不哭，痛痛飞走吧 读后感(一)：愿这世上有爱

如果你在深夜醉酒驾车，撞倒了一名过路的十七岁少女，车轮从她身上碾过去，你会怎么做？

大多数人的第一反应大概是惊恐、逃避，或者在绝望中等待警笛的响起。这是人类面对罪恶时的本能反应。但在《不哭不哭，痛痛飞走吧》的开篇，三秋缒给出了一个近乎诡异的转折：被撞倒在血泊中的少女日隅雾子并没有立刻死去，她拥有一种奇异的能力，可以把自己遭受的伤害“延后”。她把自己的肉体伤势冻结在未来的某个时间点，而她的意识却寄宿进了肇事者——二十二岁的汤上瑞穗的体内。

在三秋缒的世界里，爱从来不会发生在健康、体面、阳光普照的坦途里。他笔下的主角无一例外是世俗意义上的“社会性残次品”。二十二岁的瑞穗，内心是一潭空虚自毁的死水；而十七岁的雾子，是一具被家庭暴力与集体霸凌折磨得千疮百孔的活尸。真正的爱，绝不是正常人锦上添花的温情社交，而是两个被世界彻底剥夺了尊严与未来的畸零人，在深渊的最底层，通过彼此鲜血淋漓的空洞，严丝合缝地咬合在了一起。

如果你的生命只剩下最后十天，你会怎么做？

雾子给出的回答，不是找个安静的角落等待大限来临，更不是什么温情脉脉的告别，而是一场冷酷而血腥的清算。

通过“延后”借来的时间极其短暂，只有短短十天左右。这就像一张高利贷的借据，被推迟的内脏破裂和骨折并没有消失，只是在十天之后等着连本带利地索命。在死期到来之前，雾子从书包里拿出一把锋利的裁缝剪刀，平静地要求身为杀人凶手的瑞穗充当她的司机，带她去找那些曾经毁掉她人生的人复仇。

然而，杀人并不是一件轻而易举的事。在接连解决掉最初的几个目标之后，到了第五、六天，身心俱疲的少女在剧烈的呕吐、脚软和浑身伤痛中，其实已经产生了动摇，甚至不想再继续复仇了。瑞穗的心里也曾闪过退意，想着不如就这样陪她度过剩下的几天，吃点好吃的，买买衣服，不再杀人。

可就在这个节骨眼上，瑞穗却对她做出了一个极其怪异且不合时宜的告白。他看着满身伤痕的少女，认真地对她说：“我想，我喜欢上你了……你第一次在我眼前杀人的时候，看到你制服衬衫溅到对方的血、拿着剪刀俯瞰尸体的模样，我就觉得，啊啊，她好美。”

这本该是一段让人毛骨悚然的病态告白。但在这里，三秋缒触碰到了他关于爱最核心的审美经验——**神圣的共犯结构**。

世俗的爱总是劝人“改邪归正、重回正轨”，但在三秋缒的笔下，爱是对这个烂透了的人间规则的彻底背叛。既然整个世界都在欺凌你、嫌弃你、视你为瘟神，那我们就在深渊里结成彼此唯一的同谋。你的污垢、你的残暴、你衬衫上的鲜血，在旁人眼里是可怕的罪孽，唯独在我眼里是不可方物的绝美。

对于一个从小尊严就被践踏在泥水里的女孩而言，在生命的最后关头，听到杀害自己的凶手夸赞自己伤痕累累的模样“很美”，带来了某种灵魂深处的震颤。雾子紧紧握住了瑞穗的手，低声说，虽然不知道他有几分真心，但自己真的非常开心。

正是这个告白，让雾子重新握紧了那把冰冷的裁缝剪刀。更不可思议的是，接下来的复仇在两人的共谋下，竟然生出了一种近乎疯狂却又久违的“快乐”。

他们开着那辆旧车在黑夜与暴雨中穿行，猎杀父亲、继姊、带头霸凌的同学与冷漠的班主任，一共夺走了十七条人命。中途他们被警察抓捕过四次，受过两次重伤，但全都被雾子用异能强行抹平。直到在染满枫红的树林里杀完第十七个人之后，少女竟然天真地牵起瑞穗的双手，在纷飞的落叶中像八音盒上的人偶一样转个不停，脸上露出了孩童般灿烂的笑容。

那是两个被全人类放逐的孤魂，在罪恶与毁灭的深渊里，偷尝到的最自由、最纯粹的狂喜。

可这场复仇名单上的最后一个人，原本就是瑞穗自己。

在解决了所有人之后，雾子拿着剪刀跨坐在瑞穗身上，冰冷的刀尖直接抵住了他的胸口。瑞穗不仅没有反抗，反而满心期待着那一刀刺下来。对他而言，能被这个少女杀死，既是对车祸罪孽的偿还，也是一种彻底的解脱。

然而雾子却在最后一刻把剪刀扔在了一旁。她看着渴望赴死的瑞穗说：“杀一个这么想被杀的人，又怎么能算是复仇呢？我不成全你唯一的愿望……这就是我对你的复仇。”

说完，少女整理好衣服，头也不回地走进了雨夜。

如果摆在你面前的，是一个可以彻底抽身、回归温暖平静生活的机会，你会怎么做？

雾子离开后，隔壁的艺大生三枝走进了瑞穗混乱的房间。她按停了播放器，点燃香烟，笨拙地跟瑞穗聊起即将到来的冬天：聊起清晨被除雪车摇醒的震颤、窗外被刷成纯白的世界，以及在寒冷的冬夜回到房间、喝一杯放满糖的热咖啡。

这个极具吸引力的艺大生，代表了现实世界向瑞穗递出的最后一条生路。只要瑞穗停下脚步，他就可以彻底告别这趟血腥疯狂的噩梦，不用再去当杀人的共犯，也不用背负十天之后的死亡倒计时。他完全可以留在这个有暖气、有香烟、有热咖啡的人间，变回一个普通的大学生，去拥有一段安稳、平静的正常生活。

艺大生看着他，轻声说：“如果你还是要去找那个死神，我不会阻止你……你走了，我会很寂寞的。”

但瑞穗做出了选择。他没有留恋这唾手可得的温暖，他系紧鞋带，穿上大衣，和艺大生握手告别，毫不犹豫地推开门，一头扎进了冰冷的风雨中，去追赶那个注定要带他走向覆灭的少女。

在常人看来，这是不可理喻的疯狂。但三秋缒在此处刻画的，正是爱最纯粹的排他性：世俗的幸福再安稳、再温暖，终究只是无足轻重的浮云；对于一个早已灵魂死寂的人而言，那个浑身伤痕、满手鲜血的少女，才是他在这荒诞人世间唯一确认过的真实。

在追寻雾子的路上，随着记忆的层层剥离，瑞穗才惊骇地发现，眼前这个被自己撞死、又为了复仇杀红了眼的少女，究竟是谁。

那是十年前和他隔着邮筒通信的笔友。

十二岁那年，两个在现实中饱受折磨的孩子，在信件里讨论过一个严肃的问题：世上到底有没有爱？

当时的雾子饱受家庭暴力的凌虐，对世间虚伪的情感深恶痛绝；而瑞穗内心一片虚无，习惯性自毁自弃。面对雾子的困惑，十二岁的瑞穗在回信里写道：“如果说的那种‘爱’并不是真的存在，而是不知道从哪里来的谁擅自创造出来的概念，我反而会觉得还挺感动的……如果这是人造的，那么我想‘爱’也许就是人类最伟大的发明，或者是全世界最温柔的谎言。”

为了守护这个“全世界最温柔的谎言”，他们在长达五年的通信中小心翼翼地撒着谎。瑞穗装成一个健康阳光的现充少年，雾子装成一个安稳平淡的女高中生。他们不敢把身上的淤青、烫伤和脓血写进信里，因为在他们的认知里，“爱”太神圣了，绝不能被自己溃烂的人生所玷污。他们宁可把痛苦咬碎了咽进肚子里，也要在信纸上给对方留下一片干净的天空。

十七岁那年，当继父的暴虐要把雾子逼上绝路时，瑞穗打破了书信的距离。他赶到雾子家，拿起菜刀砍死了那个施暴的恶魔。然而在逃亡途中的游乐园里，云霄飞车发生了机械故障，瑞穗为了护住雾子，肉体在一瞬间被碾成了一摊肉泥。

如果获得爱的后果，是彻底毁灭对方的人生，你会怎么做？

看着为了保护自己而粉身碎骨的恋人，十七岁的雾子陷入了毁灭性的绝望。她坚信自己是个“瘟神”，是她招来了继父，害死了母亲，如今又害死了瑞穗。

于是，在云霄飞车的残骸前，她做出了一个惨烈到令人窒息的抉择：她发动了前所未有的大规模异能，将自己和瑞穗相遇重逢的一切现实“全部取消”。她抹去了瑞穗来找她的事实，抹去了杀人和事故，将瑞穗完好无损地复原成一个普通高中生，送回人间去过正常人的生活。

而她留给自己的代价，是把肉体与时间永远冻结在十七岁。为了不让因果再次连累瑞穗，她选择独自留在那个充斥着虐待与凌辱的高中地狱里，把那段生不如死的高中岁月，一天一天、咬着牙重新熬了整整五年。

在三秋缒的笔下，最高等级的爱从来不是占有与厮守，而是一种决绝的**自我抹杀**。

这是一种彻底打破了世俗功利交换的爱——我爱你，不仅不需要你的回报，甚至不准你知道我的存在。如果我的爱会成为你的诅咒，那我宁可把自己连根拔起、神形俱灭，独自在地狱里把折磨重走一遍，只要你能干干净净地活在阳光下。

可命运偏偏如此讽刺。五年之后，完全失去记忆的二十二岁瑞穗，成了个平庸窝囊的大学生，却在那个雨夜里喝醉了酒，一脚油门，再次撞倒了那个容颜停滞在十七岁的雾子。

因果律在这里收紧成了一个绝对的死结。

十天延后的时限一旦用尽，雾子就会死去；而随着雾子的死亡，五年前她施加的“取消”魔法就会失效，十七岁死在云霄飞车上的瑞穗就会重新复原为死亡状态；而瑞穗如果早在十七岁就死了，二十二岁开车撞死雾子的瑞穗就根本不曾存在。

这是一道在逻辑上注定双双湮灭的难题。没有救赎，没有生路，只有虚无。

故事的终点，是在暴风雪席卷的废弃游乐园。

那座生满铁锈的摩天轮在寒风中摇晃。异能彻底失效，被压制了五年的时间洪流重新灌注进雾子的身躯。在短短几分钟里，她在漫天飞雪中褪去了少女的躯壳，迅速长成了真实的、属于二十二岁的成年模样。闭园广播断断续续地回荡着，仅存的几盏路灯逐一熄灭，黑暗慢慢围拢过来。

他们坐在摩天轮前冰冷的长椅上，十指交握，平静地想起了十年前在信里讨论过的那个话题。

雾子在快要吻上去的时候轻声说：“结果‘**那个**’似乎真的存在呢。”

瑞穗点点头说：“是啊，看来‘**那个**’不是什么温柔的谎言。”

雾子微微笑着说：“似乎是这样。最后能知道这件事实在太好了。”

这是三秋缒在全书中最震撼人心的哲学反转：**谎言的本体论逆转**。

在冰冷客观的自然法则里，原本或许真的不存在什么“爱”，人类最初或许真的只是为了逃避虚无而编造了一场“全世界最温柔的谎言”。可是，当两个弱小的凡人愿意为了这个谎言提起菜刀、愿意为了它粉身碎骨、愿意为了它重走五年地狱、愿意在因果湮灭的死局面前十指相扣时——他们所支付的惨烈血肉代价，反过来把这个虚构的概念，硬生生锻造成了不可动摇的真实实体。

世界依然冷酷残忍，坏人早已杀尽，但生活没有变好，他们也没能逃出那个吞噬一切的地洞。但在生命的最后几秒钟，在两双手死死相扣的那一刻，“爱”真实地存在过，它超越了生死，击碎了因果，战胜了荒谬。

瑞穗在最后的弥留之际想：我对这个世界讨厌得要命，却又觉得这个世界好美。虽然有一大堆悲伤得承受不住的事，但对于以人类的身分诞生在这个世界上，我并不怨恨。只要有这些美好的回忆，我就能够和这个世界背对背牵起手。

背对背牵起手——三秋缒从不写廉价的逆风翻盘，“痛痛”从来不会真的飞走，爱也救不了肉身，它无法融化整个冬天的酷寒。

但爱是一根在暴风雪夜里划亮的火柴。它不能改变世界的冰冷，但它能让你在冻死前的那一秒钟，看清对方的眼睛。

他们绝不向这个充满暴力的世界转过身去妥协，他们始终面对着残酷的黑暗；但在他们的背后，两只手却死死扣在一起。

瑞穗摸了摸雾子的头发，念出了最后那句傻气的咒语：“不哭不哭，痛痛飞走吧。”

这句话不再试图在物理上消除伤痛，而是灵魂在面对不可逆的苦难时，所能展现出的最高尊严与极致温柔。

“愿这世上有爱”——三秋缒写下这句话时，指向的绝非某种廉价的温情。在这个故事里，恶人从未真正伏法，世界从未变得讲理，而那个将无辜者吞噬殆尽的阴暗地洞，也自始至终敞开着漆黑的巨口。现实的重力是如此沉重，以至于他们连活到明天的权利都不曾拥有。可正是在这片连神明都不曾垂怜的废墟之上，两个满身伤痕的灵魂，却在走向消亡的前一刻，平静地完成了对整个冷漠宇宙的最终答辩。

痛苦是真实的，死亡是真实的，因果的死结也是真实的。但当他们十指相扣、在风雪中吻向彼此的那一刻，那个曾经被当作“全世界最温柔的谎言”的虚构，便拥有了超越这世上一切现实的重量。他们改变不了注定毁灭的宿命，却用这一瞬的相拥，彻底剥夺了虚无对他们的审判权。

愿这世上有爱。
