# 19 常见误区与概念辨析

> [!info] 导航
> 所属篇章：[[6.积和式|积和式]]　·　第 19/22 节
> 章节索引：[[6.积和式/00-章节索引|目录]]
> 上一节 [[6.积和式/18-练习详解|练习详解]]　·　下一节 [[6.积和式/20-公式速查与方法选择|公式速查与方法选择]]

| 误区 | 错误想法 | 正确认识 |
| --- | --- | --- |
| 符号照搬 | 三阶积和式也按行列式写三正三负 | 所有排列项系数均为 $+1$ |
| 相同行 | 两行相同会使积和式为零 | 相同行不产生反对称抵消；例如 $\operatorname{per}(J_2)=2$ |
| 行消元 | 行加法像行列式一样保持数值 | 积和式只对固定一行线性，行加法一般改变答案 |
| 矩阵乘法 | $\operatorname{per}(AB)=\operatorname{per}(A)\operatorname{per}(B)$ | 一般不成立，$A=B=J_2$ 即为反例 |
| Vandermonde 照搬 | 相同行给出零点，所以仍有差积因子 | Vandermonde 积和式是对称多项式；相同行通常不使其为零 |
| Schur 补照搬 | 分块积和式也可用逆矩阵消块 | 一般分块矩阵没有 Schur 补积和式公式；只有块三角等特殊结构可直接分解 |
| 秩一扰动是一阶式 | $\operatorname{per}(A+uv^{\mathsf{T}})$ 只比 $\operatorname{per}(A)$ 多一项 | 一般会出现从 $1$ 阶到 $n$ 阶的全部子积和式，见式(36) |
| 全体元素平移 | $\operatorname{per}(A+tJ)$ 关于 $t$ 至多一次 | 一般次数为 $n$，最高次项为 $n!t^n$ |
| 有解即易数 | 能快速找到一个匹配，就能快速数出全部 | 存在性在多项式时间内可判定，精确计数一般为 $\#\mathrm P$-完全 |
| 求和等于最优 | 积和式给出最佳指派 | 它给出所有指派的总权重；最佳指派是另一类优化问题 |
| 无偏即准确 | 随机估计量期望正确就一定高效 | 还需控制方差和样本复杂度 |
| 只看行度数 | 每行都有非零元就一定有完美匹配 | 必须满足所有行子集的 Hall 条件 |
